# AdPurge —— APK 去广告编辑器

一个 Android 应用，用于去除 APK 文件中内置的广告 SDK 插件。支持 DEX 字节级直接修补、Manifest 清理、assets 广告配置删除，无需反编译 smali。

**当前版本：v5.0（最终开源版）**

> ⚠️ **最终开源版声明**：本版本为最终开源版，作者本人**后续不再更新**。作者不留个人信息，就是怕被反复找上门反馈问题、要求改这改那；分享这个项目的初心，是希望大家能自己动手做得更好，而不是提要求让作者来实现。部分新增功能未经过大量测试，如有问题请自行解决。

## 核心功能

- **一键去广告**：自动检测 14 家主流广告 SDK 厂商（腾讯GDT、穿山甲Pangle、快手、百度、谷歌AdMob 等），弹窗自由选择处理哪些厂商
- **DEX 直接修补**：字节码层面置空广告方法、阻断广告 so 加载调用、强制返回 false/true，安全策略防闪退
- **批量处理**：文件多选，逐个自动处理 + 完成后汇总报告与通知
- **断点续传**：处理中断后再次选择同一 APK 自动断点恢复，跳过已完成阶段直接打包
- **一键杀签**：去除签名校验（双条件判定防误伤），处理前三态警告（取消/仍要处理/去签并处理）
- **双线程并行**：内存充足时 DEX 并发修补、批间串行控峰值内存，低内存设备自动单线程
- **在线特征库更新**：从 URL 下载 JSON 特征库，与当前配置按分类合并去重
- **处理期间前台服务防杀**：处理中切后台不被系统杀进程（前台服务常驻通知），被用户主动强杀由断点续传兜底
- **无广告 DEX 预检跳过**：不含所选厂商特征的 DEX 直接跳过，不处理不写回（勾选厂商越少处理越快）
- **处理报告**：完成后自动生成 Markdown 格式修改报告（与 APK 同目录，DEX 级统计 + 杀签/倒计时缩短统计 + 体积/耗时对比）
- **去除 VPN/虚拟机检测**：DEX 修补去除应用对 VPN 环境和模拟器的检测
- **权限管理**：解析 APK 权限列表，勾选去除不需要的权限
- **Manifest 清理**：手动或自动清除广告组件与权限注册
- **加固检测**：自动识别 360/腾讯/梆梆等加固壳并给出警告
- **广告特征配置**：自定义广告 SDK 包名/类名/方法名/URL 等特征
- **处理日志一键复制**：日志面板一键复制全部内容

## 性能特点

- 处理全程流畅：彻底根治处理中卡死 / 崩溃 / 内存爆炸
- 处理速度：同规格 APK（51.8MB / 9 DEX）实测总耗时 62.3s（v3.0 单线程），同类工具 82.9s，快 25%；v5.0 实测 DEX 修补 48.1s（快 6%）、总耗时 65.2s（含杀签预扫描等新环节）；双线程并行需 ≥700MB 堆设备触发，低内存设备自动单线程
- 处理后 APK 体积小于原始（丢调试信息瘦身，实测 51.8MB → 49.5MB）
- 日志精简清晰：每个 DEX 仅 2~3 行进度汇总

## 技术架构

| 组件 | 技术 |
|------|------|
| 语言 | Kotlin |
| DEX 处理 | dexlib2 (smali/baksmali) |
| APK 签名 | apksig (v1+v2+v3，随机密钥自持) |
| ZIP 处理 | java.util.zip (标准压缩) |
| DEX 处理模式 | 批内并发 + 批间串行（双线程可控），流式预检跳过（无广告 DEX 不加载不写回） |
| 断点续传 | 检查点落盘 + 固定工作目录恢复 |
| UI | Material Components + AppCompat |

## 项目结构

```
├── app/
│   ├── src/main/java/com/ads/purge/
│   │   ├── core/
│   │   │   ├── DexPatcher.kt        # DEX字节级直接修补（核心引擎）
│   │   │   ├── AdRemover.kt         # 去广告流水线调度
│   │   │   ├── AdVendor.kt          # 广告SDK厂商特征库（14家）与识别
│   │   │   ├── AdPatternConfig.kt   # 广告特征配置管理
│   │   │   ├── ApkProcessor.kt      # APK解包/打包（ZIP处理）
│   │   │   ├── Signer.kt            # APK签名（v1+v2+v3，随机密钥自持）
│   │   │   ├── AdManifestCleaner.kt # Manifest清理
│   │   │   ├── AxmlEditor.kt        # AXML二进制编辑
│   │   │   ├── DexHandler.kt        # DEX↔Smali转换
│   │   │   └── ...
│   │   ├── MainActivity.kt          # 主界面（功能卡片+处理流水线）
│   │   └── ...
│   └── build.gradle
├── CHANGELOG.md
├── LICENSE
└── README.md
```

## 构建与安装

需要 Android Studio + Gradle + Android SDK。

```bash
# 编译 Debug APK
./gradlew assembleDebug

# 安装到设备
adb install app/build/outputs/apk/debug/app-debug.apk
```
